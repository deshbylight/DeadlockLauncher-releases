# Deadlock Group Finder — установка

Страница установки: **https://deshbylight.github.io/DeadlockLauncher-releases/**
(кнопка «Скачать установщик»). После установки лаунчер сам обновляется.

Здесь лежит только адрес сервера (`server.json`) и страницы для игры (`skins/`); установщики и
обновления раздаёт сервер лаунчера.

Лаунчер — фанатский инструмент с открытой лицензией MIT, не связан с Valve. Deadlock — игра Valve.
